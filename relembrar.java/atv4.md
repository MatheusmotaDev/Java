🔵 Nível 4: O Laço while (Enquanto)
O for é ótimo quando você sabe exatamente quantas vezes quer repetir algo. Mas e quando você não sabe? Imagine uma tela de login: o sistema não sabe quantas vezes o usuário vai digitar a senha errada, ele simplesmente repete a pergunta enquanto a senha estiver incorreta.

O Desafio:

Crie uma variável int contador = 0.

Crie um laço while que continue rodando enquanto o contador for menor que 3.

Dentro do laço, imprima "Carregando..." e, logo abaixo, some 1 ao contador (exemplo: contador = contador + 1; ou contador++;).

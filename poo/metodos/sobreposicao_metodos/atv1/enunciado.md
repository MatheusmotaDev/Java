Exercício — Produto

Uma loja precisa representar seus produtos. Cada produto possui:

nome
categoria
preço

Crie a classe necessária para representar um produto.

Além disso, quando o sistema precisar transformar um produto em texto, ele deve apresentar nome, categoria e preço em uma única informação textual.

No programa principal, crie um produto e exiba-o usando System.out.println().

Regras:

Use um construtor para inicializar os dados.
Sobrescreva toString().
O toString() deve usar return.
Não coloque System.out.println() dentro do toString().

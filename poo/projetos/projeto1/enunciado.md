Sistema de Biblioteca

Uma biblioteca deseja desenvolver uma primeira versão de seu sistema para organizar seu catálogo. Cada livro cadastrado possui título, ano de
 publicação e informações sobre seu autor.
 
 
  O autor possui nome e nacionalidade.

O sistema deve permitir cadastrar livros e autores e exibir as informações completas de um livro, incluindo os dados de seu autor.

No programa principal, cadastre pelo menos um livro e um autor e apresente suas informações.







Classes e objetos — Livro e Autor.
Atributos — informações que cada objeto guarda.
Construtores — incluindo default e com parâmetros.
this — dentro dos construtores.
Métodos — por exemplo, para exibir informações.
new — criação dos objetos.
Associação entre classes — Livro se relaciona com Autor.
Acesso aos atributos através da associação — o livro consegue acessar os dados do autor relacionado.
Classe Main e main — onde os objetos são criados e utilizados.
